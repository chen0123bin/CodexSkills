## 项目概览

- 总里程碑数: 6
- 预估总任务数: 11
- 关键路径: M1 → M2 → M3 → M5 → M6

---

## 里程碑清单

### M1: 项目基础与本地数据层

- **目标**: 搭建可运行的前端项目骨架，并建立任务数据模型与本地持久化能力。
- **交付物**: React + TypeScript + Vite 项目脚手架、基础样式体系、任务类型定义、本地存储仓储层。
- **验收标准**:
  - [ ] 项目可以本地启动并渲染基础应用壳。
  - [ ] 任务数据可以在浏览器本地完成读写与初始化。
- **依赖**: 无
- **包含任务**: T001, T002
- **状态**: `pending`

---

### M2: 今日清单核心流程

- **目标**: 交付围绕“今天”展开的任务展示与 CRUD 核心闭环。
- **交付物**: 今日任务页、任务列表、任务新增编辑表单、完成/删除操作。
- **验收标准**:
  - [ ] 用户可以在今日页新增、编辑、删除、完成和重新打开任务。
  - [ ] 今日页默认聚焦当天任务，未完成任务展示优先。
- **依赖**: M1
- **包含任务**: T003, T004
- **状态**: `pending`

---

### M3: 分类、优先级与筛选体验

- **目标**: 让用户可以更清楚地组织任务，并快速找到重要事项。
- **交付物**: 分类配置、优先级展示、筛选与排序控件。
- **验收标准**:
  - [ ] 任务可设置分类和优先级，并在列表中清晰展示。
  - [ ] 用户可按分类、优先级和完成状态筛选任务。
- **依赖**: M2
- **包含任务**: T005, T006
- **状态**: `pending`

---

### M4: 历史回看与每日统计

- **目标**: 为用户提供最基础的复盘能力，让工具不止是“打勾清单”。
- **交付物**: 每日统计卡片、历史记录页、按日期查看任务能力。
- **验收标准**:
  - [ ] 今日任务总数、已完成数和完成率可以正确展示。
  - [ ] 用户可以查看历史日期的任务列表与完成情况。
- **依赖**: M2
- **包含任务**: T007, T008
- **状态**: `pending`

---

### M5: 本地持久化加固与体验优化

- **目标**: 提升产品稳定性和可用性，确保本地优先策略在真实使用中可接受。
- **交付物**: 数据恢复流程、存储异常提示、空状态、响应式和基础可访问性优化。
- **验收标准**:
  - [ ] 刷新页面后任务和历史数据可以恢复。
  - [ ] 桌面端和移动端浏览器均可完成核心任务操作。
- **依赖**: M3, M4
- **包含任务**: T009, T010
- **状态**: `pending`

---

### M6: 质量验证与发布准备

- **目标**: 对核心流程做最终验证，并补齐使用与部署说明。
- **交付物**: 基础测试或冒烟验证、构建通过记录、使用文档与静态部署说明。
- **验收标准**:
  - [ ] 核心用户路径完成验证，构建产物可正常生成。
  - [ ] README 中包含运行、构建和本地存储限制说明。
- **依赖**: M5
- **包含任务**: T011
- **状态**: `pending`
