## 使用规则

- 每次启动工作流时先读取本文件，再读取 `manifest.yaml` 和当前 phase 文档。
- 只记录跨 phase、跨 task、跨版本仍然重要的信息。
- 当用户明确要求“记住”时，必须写入本文件。
- 默认不要主动写入；如果没有用户明确要求记住，就不要写入本文件。
- 每条记忆必须包含 `记录时间`、`记录原因`、`内容主体`。
- `内容主体` 必须精简，避免写入临时过程噪声或 task 级别细节。
- 不要记录每一步操作、普通进展、命令输出或过程流水。
- 所有时间字段统一使用本地时区格式 `yyyy-MM-dd HH:mm:ss`。
