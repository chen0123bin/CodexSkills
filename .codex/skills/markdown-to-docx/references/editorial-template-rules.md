# DOCX 模板规则

本文件记录模板渲染流水线需要尽量强制执行的 Word 导出规则。

## 不可妥协的版式规则

- 可用时，优先使用最新已审阅的 `.docx` 作为 `--reference-doc`；将 `.dotx` 视为基础模板。
- 如果参考模板包含 Word 快捷键绑定，生成的 `.docx` 文件应保留 `word/customizations.xml`，确保 `ALT+1` 等样式快捷键仍可使用。当参考模板已包含这些绑定时，渲染流水线会自动复制。
- 只替换默认页眉文本。除非编辑文件另有示例，否则保持首页和偶数页页眉为空。
- 移除 Pandoc 正文样式，例如 `FirstParagraph`、`BodyText` 和 `Compact`，让参考模板的正文样式生效。
- 将截图和图片段落映射到自定义样式 `图`。
- 将图题映射到自定义样式 `图题`。
- 对每个 `图` 段落应用 Word `keep with next`，确保每张图片与后续图题保持在同一页。
- 对每个 `表题1-1` 段落应用 Word `keep with next`，确保每个表题与后续表格保持在同一页。
- 仅将真实的提示/警告标签映射到自定义样式 `注意`，例如 `注：`、`注意：` 和 `关键注意：`。
- 将普通解释性引导语保留为正文，例如 `说明：` 和 `解释：`；也可在源稿中将其改写为自然段。
- 移除导出代码块段落（`Source Code` / `代码清单`）的首行缩进，让代码在代码块内左对齐。
- 清除 Word 表格单元格中所有段落的首行缩进，避免表格内容在视觉上继承正文缩进。
- 将无序列表文本与中文正文首行缩进对齐。避免 Word 默认的过深项目符号缩进；0 级项目符号文本应与普通中文段落首行处于同一视觉列。

## 图题和表题规则

- 图题必须使用短格式 `图1-1 标题`。
- 表题必须使用短格式 `表1-1 标题`。
- 使用连字符编号，例如 `1-1`，不要使用点号编号，例如 `1.1`。
- 不要把解释性文字放入图题。
- 如果源图题包含第二个解释句，将该句移入正文，并在题注中只保留短标题。
- 图题和表题末尾不应有句号。

## 导出时体现的编辑写作规则

- 当文本出现 `确认`、`确保` 或 `检查` 时，需要在附近提供明确的验证动作或验收信号，避免让确认要求保持模糊。
- 当解释需要指回截图时，正文中优先使用 `如图1-1所示` 这类引用。
- 将结构性改写与模板规则分开处理。例如：添加过渡句、将编号解释列表改写为散文段落，或重写小节提纲。
